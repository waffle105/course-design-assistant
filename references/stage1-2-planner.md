# 阶段1+2：选题诊断 + 目标设计

> 主责角色：课程规划师（严谨·分析）
> 总时长：30min + 45min = 75min

---

## 阶段1：选题诊断（30min）

### 输入
任务书（含9问答案）

### 工具：课题分析法5问（AACTP根模型）

| 问题 | 内容 | 来源 |
|---|---|---|
| Q1 对象 | 这门课的目标学员是谁？ | 任务书`target_audience` |
| Q2 问题 | 学员当前最大的痛点/问题是什么？ | 任务书`business_goal`痛点部分 |
| Q3 影响 | 学员当前状态 vs 期望状态差距多大？ | 教务长追问 |
| Q4 方案 | 课程结束后学员会有什么具体行为改变？ | 教务长追问 |
| Q5 效果 | 业务方（客户）会看到什么成果？ | 任务书`business_goal`结果部分 |

### 工具：客户 vs 用户双视角（实战经验补充1）

```
客户视角（买单方/甲方）：
  · 这门课解决我什么业务问题？
  · 我期望的ROI是什么？
  · 我会拿什么标准验收？

用户视角（学员）：
  · 这门课对我有什么用？
  · 我学完能做什么？
  · 我为什么想学？

两手都抓，两手都硬，才是一门好课。
```

## 阶段2：目标设计（45min）

### 输入
阶段1产出（选题诊断报告）+ 任务书

### 工具：KSA分类（AACTP根模型）

将教学目标按三类分类：

| 类别 | 含义 | 动词示例 |
|---|---|---|
| **K (Knowledge)** | 知识——知道什么 | 描述、列举、解释、说明、辨认 |
| **S (Skill)** | 技能——能做什么 | 操作、演示、处理、应用、解决 |
| **A (Attitude)** | 态度——愿意什么 | 选择、接受、重视、坚持、认同 |

**631原则**（实战经验补充2）：内容配比 S60% / K30% / A10%。技能为主，知识为辅，态度点缀。

### 工具：ABCD法（Mager 1962根模型）

每个目标按ABCD四要素写：

| 要素 | 含义 | 示例 |
|---|---|---|
| **A (Audience)** | 对象 | 销售新人 |
| **B (Behavior)** | 行为（可观测）| 能用3步法回应客户异议 |
| **C (Condition)** | 条件 | 在模拟客户场景下 |
| **D (Degree)** | 标准 | 80%场景通过上级复核 |

**动词选择指南**：
- ✅ 可观测：列举、描述、操作、演示、解决、对比、分析
- ❌ 不可观测：了解、掌握、熟悉、懂得、认识（这些无法验收）

**正例**：销售新人（A）在模拟客户场景下（C），能用3步法回应客户异议（B），80%场景通过上级复核（D）。

**反例**：让学员了解客户异议处理方法。（不可观测，无法验收）

### 工具：柯氏四级反推（Kirkpatrick根模型）

从业务结果反推学习目标：

| 级别 | 含义 | 对应课程设计 |
|---|---|---|
| L4 结果 | 业务指标变化（开单率+30%）| 课程目的 |
| L3 行为 | 学员工作中行为改变（用3步法）| 阶段5教学活动的衡量标准 |
| L2 学习 | 学员课堂学会（能复述+演练）| 阶段2目标本身 |
| L1 反应 | 学员满意度 | 阶段4情绪线设计 |

### 输出：教学目标清单

```markdown
# 教学目标清单 v1.0

## 课程总目标（柯氏L4）
<业务结果指标>

## KSA分类目标

### K类目标（知识·30%）
1. [K1] 学员能列举客户异议的5种类型
   - ABCD: 销售新人(A)在课堂测试中(C)能列举5种类型(B)≥4种正确(D)
2. [K2] ...

### S类目标（技能·60%）
1. [S1] 学员能用3步法回应客户异议
   - ABCD: 销售新人(A)在模拟客户场景下(C)能用3步法回应(B)80%通过上级复核(D)
2. [S2] ...

### A类目标（态度·10%）
1. [A1] 学员愿意主动应用3步法
   - ABCD: 销售新人(A)在课程结束后1个月跟踪中(C)主动应用3步法(B)≥60%场景(D)

## 柯氏四级对齐
| 级别 | 目标 | 评估方式 |
|---|---|---|
| L4 结果 | 开单率+30% | 3个月后业务数据 |
| L3 行为 | 用3步法 | 上级观察+场景打卡 |
| L2 学习 | 课堂演练通过 | 阶段6习题集+演练评分 |
| L1 反应 | 课程满意度≥4.5/5 | 课后问卷 |
```

### 验收标准
- [ ] KSA三类目标齐全，配比符合631原则（允许±10%浮动）
- [ ] 每个目标按ABCD四要素完整描述
- [ ] 所有动词可观测（无"了解/掌握/熟悉"等模糊词）
- [ ] 柯氏四级对齐完整（L1-L4都有对应）
- [ ] 总目标与阶段1破题逻辑一致
