# 阶段3：结构搭建

> 主责角色：结构设计师（系统·架构）
> 标准时长：60min

## 输入
阶段2产出（教学目标清单）+ 任务书

## 工具：三种结构类型（AACTP根模型）

| 类型 | 特点 | 适用 |
|---|---|---|
| **要素型** | 按内容要素并列展开 | 知识类课程（如"产品5大功能"）|
| **流程型** | 按时间/步骤顺序 | 技能类课程（如"销售7步法"）|
| **WWH型** | Why→What→How（+IF） | 综合类课程（最常用）|

**选择依据**：
- K类目标为主 → 要素型
- S类目标为主 → 流程型
- KSA混合 → WWH型（推荐，对应"四棵树"）

## 工具：四级大纲（实战经验补充1）

```
Level 1 主题
  └─ Level 2 单元（3-5个，对应阶段2的K/S/A分类）
       └─ Level 3 章节（每单元3-4个，对应四棵树）
            └─ Level 4 知识点（每章节2-4个，颗粒度可教学）
```

**单元类型**（实战经验补充1）：
- 导入型单元：开场+破冰+课程目标
- 主体型单元：核心内容（多个）
- 总结型单元：复盘+行动计划+结束

## 工具：四棵树（实战经验补充1）

WWH型结构下，每个单元按四棵树组织：

| 树 | 含义 | 讲什么 |
|---|---|---|
| **WHY（结论树）** | 为什么学这个 | 建立认知，连接业务痛点 |
| **WHAT（观点树）** | 这是什么 | 搭建框架，定义概念 |
| **HOW（操作树）** | 怎么做 | 具体步骤+工具+演示 |
| **IF（应用树）** | 怎么用 | 迁移场景+练习+案例 |

## 工具：1331课模（实战经验补充2）

从素材到课模的转化工具：

```
1个 主题
 └─ 3个 单元（导入/主体/总结 或 三个核心模块）
     └─ 3个 章节（每单元3个章节）
         └─ 1个 知识点（每章节1个核心知识点）
```

适合2小时内的小课。大课可扩展为"1主题→4单元→12知识点"（实战经验补充1的画布版）。

## 验收标准
- [ ] 结构类型选择正确（与KSA配比一致）
- [ ] 4级大纲完整（主题→单元→章节→知识点）
- [ ] 单元类型标注（导入/主体/总结）
- [ ] 每个章节标注四棵树类型（WWH型时）
- [ ] 每个知识点有target_ref对齐阶段2目标
- [ ] 知识点颗粒度合适（1个知识点=5-15分钟教学量）
- [ ] 总知识点数量与课时匹配（1小时≈4-6个知识点）
