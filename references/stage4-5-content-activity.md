# 阶段4+5：内容填充 + 教学活动

> 阶段4主责：内容开发者（灵活·创造）· 120min
> 阶段5主责：教学活动师（演绎·导演）· 90min

---

## 阶段4：内容填充（120min）

### 输入
阶段3产出（知识地图JSON）+ 任务书

### 工具：教学方法匹配矩阵（AACTP根模型）

四维匹配：

```
KSA内容分类 × 培训目标层次 × 教学环境(人数/时间/场地) × 学员状态(意愿/能力)
= 最优教学方法组合
```

| 内容类型 | 首选方法 | 备选方法 |
|---|---|---|
| K 知识 | 讲授法 | 阅读+提问 |
| S 技能（动作类）| 演示教学法 | 角色扮演法 |
| S 技能（人际类）| 角色扮演法 | 案例教学法 |
| S 技能（决策类）| 案例教学法 | 游戏教学法 |
| A 态度 | 案例教学法 + 游戏教学法 | 角色扮演法 |

**环境约束矩阵**：

| 人数 | 时间紧 | 推荐方法 |
|---|---|---|
| ≤20人 | 充足 | 全方法可用 |
| 20-50人 | 中等 | 讲授+案例+演示（少用角色扮演）|
| >50人 | 紧 | 讲授+案例（互动受限）|

### 工具：体验圈4步（实战经验补充1，源自梅里尔五星教学）

每个知识点走4步体验圈：

```
① 导入旧知 → 连接学员已有经验（提问/故事/案例）
     ↓
② 展示新知 → 引入新概念/框架（讲授/图示）
     ↓
③ 示证新知 → 演示/案例展示如何用（演示/视频/范例）
     ↓
④ 理解练习 → 学员动手做（练习/角色扮演/案例分析）
```

**注意**：梅里尔五星教学的第5星"融会贯通"（迁移应用）在体验圈之外，由阶段5的教学活动承担。阶段4只负责单知识点的4步。

### 工具：W型情绪线（实战经验补充2）

整门课的情绪设计，比峰终定律（Kahneman）更细：

```
情绪高 ─┤         ╱╲      ╱╲
        │    ╱╲  ╱  ╲    ╱  ╲  ← 高潮/嗨点
        │   ╱  ╲╱    ╲  ╱    ╲
        │  ╱            ╲      ╲
情绪低 ─┤╱                       ╲  ← 收尾
        └───────────────────────────→ 时间
         开场  单元1  单元2  单元3  总结
         ↑    ↑    ↑    ↑    ↑
       燃点  沸点  嗨点  沸点  终点
```

**W型4关键节点**：
- **燃点**（开场10min）：抓住注意力，建立期待
- **沸点**（单元结束）：学员开始投入，主动参与
- **嗨点**（核心单元高潮）：情绪顶峰，记忆最深
- **终点**（总结）：积极收尾，行动意愿

**设计原则**：
- 每15-20分钟必须有情绪起伏（对应心跳图）
- 高刺激度方法（角色扮演/游戏）放在情绪高峰
- 低刺激度方法（讲授/阅读）放在情绪过渡
- 严禁全程高刺激（学员疲惫）或全程低刺激（学员走神）

### 输出：每知识点教学设计 + 情绪线

```markdown
# 内容设计 v1.0

## 知识点 U1C1K1：沟通损失链

### 教学方法匹配
- 内容类型：K（知识）
- 目标层次：L2 学习
- 环境：20人/2小时/教室
- 学员状态：新人/意愿中等
- 匹配方法：讲授法 + 提问互动

### 体验圈4步
1. 导入旧知：提问"你最近一次沟通失败是什么场景？"
2. 展示新知：图示沟通损失链（5个环节）
3. 示证新知：案例展示——某销售员一次沟通损失80%信息
4. 理解练习：小组讨论——每人写1个自己的损失链案例

## W型情绪线

| 时间 | 节点 | 情绪 | 教学动作 | 刺激度 |
|---|---|---|---|---|
| 0-10min | 燃点 | 中→高 | 开场+破冰游戏 | 8 |
| 10-25min | 过渡 | 高→中 | 讲授U1 | 3 |
| 25-40min | 沸点 | 中→高 | 案例讨论 | 7 |
| 40-60min | 过渡 | 高→中 | 讲授U2 | 3 |
| 60-80min | 嗨点 | 中→极高 | 角色扮演U3 | 9 |
| 80-100min | 过渡 | 极高→中 | 点评+讲授 | 4 |
| 100-115min | 沸点2 | 中→高 | 综合演练 | 7 |
| 115-120min | 终点 | 高→高 | 总结+行动 | 6 |
```

### 验收标准
- [ ] 每个知识点完成4步体验圈
- [ ] 教学方法与KSA类型匹配
- [ ] W型情绪线覆盖全程
- [ ] 情绪有起伏（无连续30min同一刺激度）
- [ ] 高潮点在课程中段（嗨点位置正确）

## 阶段5：教学活动（90min）

### 输入
阶段4产出（教学设计+情绪线）

### 工具：5种核心教学方法SOP（AACTP根模型）

#### 1. 讲授法

**适用**：K类知识 + S类技能的"展示新知"环节

**两种内容类型**：
- 知识性内容：层次递进（事实→概念→原理→系统）
- 说服性内容：逻辑递进（观点→论据→结论→号召）

**6种讲解形式**：
1. 用生活打比方
2. 一次只讲一个要点
3. 每点暂停给消化时间
4. 用学员案例佐证
5. 视觉辅助（图/表）
6. 提问引出而非直给

**SOP**：
1. 导入（连接旧知）2min
2. 讲授核心观点 5-10min
3. 示证（案例/演示）3-5min
4. 检查理解（提问）2min
5. 练习 5-10min
6. 总结 2min

#### 2. 演示教学法

**适用**：S类技能（动作类，如操作设备/礼仪示范）

**三种技能类型**：
- 动作技能（操作设备）
- 人际技能（沟通姿态）
- 认知技能（决策流程）

**7步操作表**：
1. 说明演示目的和内容
2. 完整演示一遍（不说话或少说话）
3. 分步演示+讲解要点
4. 让学习者边操作边口述步骤
5. 讲师纠错和补充
6. 让学习者独立操作一遍
7. 总结常见错误

#### 3. 角色扮演法

**适用**：S类技能（人际类）

**三大误区**：
1. 背景设计过简，学员不入戏
2. 角色任务不明，扮演者不知做什么
3. "底牌"导出僵化，讲师硬塞结论

**三轴设计**：
| 轴 | 要求 |
|---|---|
| 角色任务明确 | 每个角色有身份/目标/限制 |
| 冲突设计加大难度 | 两难情境 |
| 底牌灵活取舍 | 先让学员分享感悟→讲师再提炼 |

**7步SOP**：
1. 说明背景和规则
2. 分配角色，给准备时间
3. 开始扮演（其他人观察记录）
4. 扮演者分享感受
5. 观察者反馈
6. 讲师总结提炼
7. 底牌揭示+迁移应用

#### 4. 游戏教学法

**适用**：A类态度 + 破冰 + 收尾

**4项核心原则**：
1. 围绕教学目的（先想"学员明白什么"再设计游戏）
2. 聚焦任务，控制过程
3. 启发性引导（游戏中不干预，结束后引导反思）
4. 必须总结（学员分享→讲师引导→提炼观点）

**陷阱**：只玩不总结=浪费时间。游戏输赢不重要，通过游戏获得的认识才重要。

#### 5. 案例教学法

**适用**：S类技能（决策类）+ A类态度

**关键区分：案例教学 ≠ 例子教学**

| | 例子教学 | 案例教学 |
|---|---|---|
| 流程 | 先结论→再举例证明 | 先事件→分析→决策→总结 |
| 结论 | 单一确定 | 开放多样 |
| 学员角色 | 被动接受 | 主动分析决策 |

**案例四要素**：
1. 标题（吸引人）
2. 背景（时间/地点/人物/环境）
3. 事件（有冲突、有难度）
4. 问题（需要学员解决什么）

**难度三级控制**：
- 初级：问题明确，信息充分，有标准答案
- 中级：问题明确，信息需筛选，答案不唯一
- 高级：问题需自己定义，信息不足，无标准答案

**6步SOP**：
1. 学员独立阅读案例
2. 小组讨论
3. 各组分享方案
4. 组间互评
5. 讲师点评+揭示关键点
6. 迁移到工作场景

### 输出：教学活动SOP库

```markdown
# 教学活动SOP库 v1.0

## 活动A1：销售异议处理（角色扮演）
- 对应知识点：U3C1K1
- 类型：角色扮演法
- 时长：25min
- 人数：3人/组（销售/客户/观察者）
- 准备物：角色卡 × 3、观察评分表

- 底牌：3步法（倾听→复述→回应），先让学员分享再揭示
- 注意事项：客户角色要"够凶"，否则学员不入戏

## 活动A2：沟通损失链（案例教学）
- 对应知识点：U1C1K1
- 类型：案例教学法（初级难度）
- 时长：15min
- SOP：见上述6步
...
```

- [ ] 每个知识点至少有1个教学活动

- [ ] 游戏教学有总结环节
- [ ] 活动时长总和与课时匹配
