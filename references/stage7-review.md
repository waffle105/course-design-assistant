```markdown
# 课程说明书

## 课程命名（ABC命名法 · 实战经验补充1）
```

### 2. 试讲模拟

教务长组织"内部试讲"：

```
试讲流程（30min模拟）：
1. 教务长扮演学员，课师按讲师手册走前3个知识点（15min）
2. 教务长记录"卡壳点"：
   - 时间控制是否准
   - 逐字稿是否自然
   - 互动设计是否落地
   - 物料准备是否齐
3. 问题清单+修改建议 → 打回对应路线
```

**试讲重点检查**：
- 开场5min能否抓住注意力（燃点是否成立）
- 角色扮演/案例教学的SOP是否可执行
- 时间分配是否合理（备课地图总时长=课时）
- PPT与讲师手册是否一致

### 3. 磨课反馈

```markdown
# 磨课反馈报告 v1.0

## 试讲记录
- 试讲人：XX
- 试讲时长：15min（模拟全课1/8）
- 模拟学员：教务长

## 问题清单
| # | 位置 | 问题 | 严重度 | 修改建议 |
|---|---|---|---|---|
| 1 | 第3页PPT | 文字过多，6×6原则违反 | 中 | 删减到6行以内 |
| 2 | 角色扮演A1 | 客户角色卡不够具体 | 高 | 补充3条客户台词 |
| 3 | 备课地图 | U2超时5min | 中 | U2内容精简 |

## 处理方式
- 问题1 → 打回课件制作路线（第1次打回，上限3次）
- 问题2 → 打回案例编撰路线（第1次打回）
- 问题3 → 课件制作路线修改备课地图
```
