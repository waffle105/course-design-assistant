# 阶段8：培训项目设计（可选，独立于1-7）

> 主责：培训项目师（统筹·项目）
> 标准时长：120min
> 触发条件：用户明确需要"培训项目"而非单门课

## 与阶段1-7的区别

| 维度 | 阶段1-7（单门课）| 阶段8（培训项目）|
|---|---|---|
| 范围 | 1门课的物料包 | 多门课的系列项目 |
| 时长 | 几小时-1天 | 几天-几个月 |
| 目标 | 单次培训效果 | 业务结果改善 |
| 输出 | 7类交付物 | 项目方案+课程系列+评估闭环 |

## 四种培训项目方向（AACTP根模型）

### 方向1：能力提升型

**适用**：针对特定岗位/层级的能力差距

**6步法**：
1. **确定培训对象**——谁需要提升什么能力
2. **厘清能力要求**——该岗位的能力标准（参考图4.4管理者能力模型）
3. **建立能力模型，匹配培训课程**——能力差距=培训需求
4. **课程的设计与开发**——基于能力模型设计系列课程（每门课走阶段1-7）
5. **系列课程的实施**——分阶段、有节奏推进
6. **效果的迁移**——确保课堂所学转化为工作所用

### 方向2：绩效提升型

**适用**：直接对焦业务指标

**6步法**：
1. **绩效目标的确定**——业务指标（非学习指标）
2. **让参与者感受到自己是受益者**——解决"与我何干"
3. **工作问题探讨与行动计划的拟定**——从课堂到行动
4. **绩效合约，保障体系**——书面承诺+监督机制
5. **阶段性的成果回顾**——定期复盘，调整方向
6. **项目总结**——数据说话，闭环交付

### 方向3：企业文化型

**适用**：从"宣讲"到"体验+认同"

**5步法**：
1. **基本思路**——不是宣讲，是体验+认同
2. **涉及对象及任务**——高层/中层/基层各有角色
3. **文化的提炼与解读**——把虚的文化变成可操作的行为
4. **文化讲师的培养**——选拔+训练+认证
5. **文化的实践与落地**——制度配套+行为考核+故事传播

### 方向4：内训师培养型

**适用**：企业内部讲师队伍建设

**5步法**（本书中最实操的项目类型）：
1. **内训师选拔**——标准+流程+淘汰机制
2. **课程选题**——与企业战略对齐
3. **体系化的讲师训练**——覆盖课程设计+教学方法+课堂管理
4. **讲师辅导和实践**——导师带教+试讲打磨
5. **课件评审及讲师通关考评**——标准化验收流程
